## АРХИТЕКТУРА — СТРОГО СОБЛЮДАТЬ

### МОДУЛЬ 1: Data Layer

#### 1.1 Получение инструментов
  Endpoint: GET https://www.deribit.com/api/v2/public/get_instruments
  Params:   currency=ETH, kind=option, expired=false
  
  Для каждого инструмента асинхронно (asyncio + aiohttp) запросить:
  
  GET /public/get_order_book
    Params: instrument_name=<name>, depth=1
    Извлечь: best_bid_price, best_ask_price, mark_price,
             greeks.delta, greeks.gamma, greeks.theta, greeks.vega,
             mark_iv, stats.volume_usd
  
  GET /public/get_order_book (тот же ответ содержит open_interest)

#### 1.2 Фильтрация инструментов — ОБЯЗАТЕЛЬНЫЕ условия
  Отбросить если:
    best_bid_price == 0 OR best_ask_price == 0     → нет ликвидности
    (ask - bid) / mark_price > 0.30                → спред > 30%
    days_to_expiry < 2                             → слишком близко
    days_to_expiry > 14                            → вне недельного окна
    mark_price < 0.001                             → мусорный контракт
    open_interest < 10                             → нет рынка

#### 1.3 Liquidity Score (вычислить для каждого инструмента)
  score = (
      (1 - spread_pct) * 0.40 +
      min(volume_usd_24h / 500_000, 1.0) * 0.35 +
      min(open_interest / 1000, 1.0) * 0.25
  )
  Отбросить если score < 0.35

#### 1.4 Единицы измерения — КРИТИЧНО
  - Deribit theta в ETH/день → умножать на SPOT_PRICE для получения USD/день
  - Premiums в USDC для USDC-margined контрактов (проверять currency)
  - Delta безразмерная [0..1] для коллов, [-1..0] для путов
  - 1 контракт = 1 ETH

### МОДУЛЬ 2: Payoff Engine

#### 2.1 Матрица пэйоффов
  Ценовые точки S (28 точек обязательно + стресс):
    primary   = np.arange(1700, 2401, 25)   # 29 точек каждые $25
    stress    = [1400, 1500, 1600, 2500, 2600, 2700]  # tail risk
    ALL_POINTS = sorted(set(primary) | set(stress))

  Payoff матрица P shape [len(ALL_POINTS), N_instruments]:
    Call: P[j,i] = max(S_j - strike_i, 0)
    Put:  P[j,i] = max(strike_i - S_j, 0)

#### 2.2 P&L вектор при цене S
  Реалистичная цена входа (НЕ mid-price):
    entry_cost[i] = ask[i]  если x[i] > 0  (покупаем по ask)
    entry_cost[i] = bid[i]  если x[i] < 0  (продаём по bid)
  
  Реализовать через вспомогательные переменные:
    x_long[i]  = max(x[i], 0)   — количество купленных
    x_short[i] = max(-x[i], 0)  — количество проданных
    cost = ask_vec @ x_long - bid_vec @ x_short
    PnL(S) = P[S] @ x - cost

### МОДУЛЬ 3: MILP Формулировка (cvxpy)

#### 3.1 Переменные
  x       = cp.Variable(N, integer=True)  # контракты [-MAX_QTY..+MAX_QTY]
  x_long  = cp.Variable(N, integer=True)  # >= 0
  x_short = cp.Variable(N, integer=True)  # >= 0
  z       = cp.Variable(N)                # |x[i]| для маржи

#### 3.2 Параметры (настраиваемые вверху файла)
  SPOT_PRICE      = 2000
  MAX_QTY         = 10
  MARGIN_BUDGET   = 5000   # USD
  PNL_FLOOR       = -400   # USD — минимальный P&L в любой точке
  PNL_CEILING     = +400   # USD — минимальный P&L при S=2200
  MAX_DELTA       = 0.15   # максимальная абсолютная дельта портфеля
  MAX_VEGA        = 600    # USD per 1% IV move
  MAX_GAMMA       = 0.008  # абсолютная гамма портфеля
  MIN_EXPIRY_DAYS = 2
  MAX_EXPIRY_DAYS = 14
  HOLDING_DAYS    = 5      # горизонт для total theta

#### 3.3 Objective — максимизировать ОЖИДАЕМУЮ theta
  Сценарии движения цены (взвешенные):
    scenarios = [
        {'spot_mult': 0.90, 'iv_shift': +0.08, 'prob': 0.10},  # crash
        {'spot_mult': 0.95, 'iv_shift': +0.03, 'prob': 0.20},  # dip
        {'spot_mult': 1.00, 'iv_shift':  0.00, 'prob': 0.40},  # base
        {'spot_mult': 1.05, 'iv_shift': -0.02, 'prob': 0.20},  # rally
        {'spot_mult': 1.10, 'iv_shift': -0.04, 'prob': 0.10},  # surge
    ]
  
  Для каждого сценария пересчитать theta через Black-Scholes
  Objective = cp.Maximize(sum(s.prob * theta_s @ x for s in scenarios))

#### 3.4 Constraints — ВСЕ ОБЯЗАТЕЛЬНЫ
  
  # P&L constraints (для каждой из 35 ценовых точек)
  for S_j in ALL_POINTS:
      if S_j == RANGE_HIGH:
          constraints += [(P[j] @ x - cost) >= PNL_CEILING]
      else:
          constraints += [(P[j] @ x - cost) >= PNL_FLOOR]
  
  # Декомпозиция x на long/short
  constraints += [x == x_long - x_short]
  constraints += [x_long >= 0, x_short >= 0]
  
  # |x| через z для маржи
  constraints += [z >= x, z >= -x]
  
  # Маржа (линейная аппроксимация с буфером 25%)
  margin_approx = margin_vec * 1.25
  constraints += [margin_approx @ z <= MARGIN_BUDGET]
  
  # Границы количества
  constraints += [x >= -MAX_QTY, x <= MAX_QTY]
  
  # Greeks constraints
  constraints += [cp.abs(delta_vec @ x) <= MAX_DELTA]
  constraints += [cp.abs(vega_usd_vec @ x) <= MAX_VEGA]
  constraints += [gamma_vec @ x >= -MAX_GAMMA]
  
  # IV stress test: что если IV +25% прямо сейчас
  # (pnl при стрессе не хуже PNL_FLOOR * 1.5)
  constraints += [iv_stress_pnl(x) >= PNL_FLOOR * 1.5]

#### 3.5 Solver
  Попробовать в порядке приоритета:
    1. cp.GLPK_MI    (установлен по умолчанию)
    2. cp.CBC        (быстрее для больших задач)
  
  solver_opts = {
      'max_iters': 10000,
      'eps_abs': 1e-6,
      'verbose': False,
      'time_limit': 30  # секунд
  }

#### 3.6 Итерационное уточнение маржи
  После нахождения решения:
    1. Запросить /public/get_margins для каждой ноги с найденным qty
    2. Если реальная маржа > MARGIN_BUDGET * 0.95 → пересчитать margin_vec
    3. Перезапустить MILP с уточнёнными данными
    4. Максимум 3 итерации

### МОДУЛЬ 4: Обработка ошибок

  INFEASIBLE → автоматически релаксировать в порядке:
    1. Расширить диапазон P&L floor на 20% (PNL_FLOOR * 1.2)
    2. Увеличить MARGIN_BUDGET на 20%
    3. Ослабить delta constraint (MAX_DELTA * 2)
    4. Если всё равно infeasible → вывести какой constraint блокирует
       (проверить каждый constraint по отдельности)
  
  API ошибки → retry с exponential backoff (3 попытки)
  Timeout MILP → вернуть best_found если есть, иначе сообщить
